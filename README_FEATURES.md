# 🎮 网页版 Minecraft 新功能说明

本次更新新增了两大核心功能：**虚拟按键系统**（移动端控制）和**真实重力模式**（结构倒塌系统）。

## 📱 虚拟按键系统（移动端控制）

### 功能概述
为移动设备提供完整的触摸控制方案，无需键盘和鼠标即可操作游戏。

### 启用方式
1. 按 `O` 键打开设置菜单
2. 在"控制设置"中找到"虚拟按键（移动端）"
3. 开启该选项

### 控制布局
- **左下角**：虚拟摇杆（用于移动）
  - 触摸拖动控制 WASD 方向
  - 支持 360° 方向控制
  - 带死区（deadzone）避免误触
  
- **右下角**：动作按钮
  - 🚀 跳跃按钮（模拟 Space 键）
  - ⚡ 加速按钮（模拟 Shift 键）
  
- **右上角**：方块操作按钮
  - ⛏️ 破坏方块（模拟左键）
  - 🧱 放置方块（模拟右键）
  
- **左上角**：特殊功能
  - ✈️ 飞行模式切换（模拟 F 键）
  
- **屏幕中心**：触摸滑动控制视角
  - 滑动屏幕旋转摄像机
  - 灵敏度与鼠标设置同步

### 技术特性
- 完全响应式设计，适配不同屏幕尺寸
- 支持多点触摸
- 视觉反馈（按钮按下高亮）
- 零延迟输入响应
- 自动退出指针锁定模式

### 注意事项
- 启用虚拟按键时会自动禁用指针锁定
- 虚拟按键在 PC 端也可用，适合测试
- 可与物理键盘组合使用

## 🌍 真实重力模式（结构倒塌系统）

### 功能概述
模拟真实物理重力，当方块失去支撑时会发生倒塌。

### 启用方式
1. 按 `O` 键打开设置菜单
2. 在"游戏玩法"中找到"真实重力模式"
3. 开启该选项

### 工作原理

#### 1. 支撑系统
方块的支撑力由三种支撑方式组成：

| 支撑类型 | 权重 | 说明 |
|---------|------|------|
| **下方支撑** | 1.0 | 方块下方有实体方块提供最强支撑 |
| **侧面支撑** | 0.3 | 四周相邻方块提供中等支撑 |
| **上方支撑** | 0.1 | 上方方块悬吊提供最弱支撑 |

#### 2. 结构完整性检测
- 当破坏一个方块时，系统检查周围 6 个方向的方块
- 使用 **BFS**（广度优先搜索）算法找出所有连接的方块
- 递归计算每个方块的总支撑力
- 支撑力 < 0.5 时，方块失去支撑

#### 3. 下落动画
- 失去支撑的方块从世界中移除
- 创建临时网格执行下落动画
- 使用真实重力加速度（20 单位/秒²）
- 落地后检测下落距离

#### 4. 碎裂规则
- **下落距离 ≤ 3 格**：方块完好，放置在落地点
- **下落距离 > 3 格**：方块碎裂消失（模拟摔碎效果）

### 使用示例

#### 示例 1：砍树
1. 启用真实重力模式
2. 找到一棵树
3. 破坏树干底部的木头方块
4. 观察：整棵树失去支撑，树叶和上方木头全部掉落

#### 示例 2：悬空建筑
1. 建造一个悬空平台（只用侧面支撑）
2. 破坏关键支撑点
3. 观察：整个结构因支撑力不足而倒塌

#### 示例 3：高空坠落
1. 在 Y=20 高度放置一个方块
2. 移除下方所有支撑
3. 观察：方块下落后因距离超过 3 格而碎裂

### 技术细节

#### 性能优化
- 限制单次检测最大方块数（500 个）
- 限制递归深度（100 层）
- 使用集合避免重复检测
- 异步下落动画不阻塞主线程

#### 特殊方块
- **基岩**：提供无限支撑（权重 10.0），永不倒塌
- **空气/水**：不参与支撑计算

#### 数据结构
```typescript
interface FallingBlock {
  position: Vector3;    // 当前位置
  blockType: BlockType; // 方块类型
  startY: number;       // 初始 Y 坐标
  velocity: number;     // 下落速度
  mesh: Mesh;          // 临时网格
}
```

### 已知限制
- 单次最多处理 500 个方块（防止卡顿）
- 不支持跨 Chunk 边界的复杂结构（将在未来版本优化）
- 下落动画期间方块暂时脱离世界网格系统

## 🐛 故障排除

### 虚拟按键无响应
- 确认在设置中已启用虚拟按键
- 检查浏览器是否支持触摸事件
- 尝试刷新页面

### 重力系统不工作
- 确认在设置中已启用真实重力模式
- 尝试破坏基岩以外的方块
- 检查控制台是否有错误信息

### 性能问题
- 降低渲染距离
- 禁用真实重力模式
- 使用现代浏览器
