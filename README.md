## 🧭 项目概述

- **项目愿景**：构建一款以 Three.js 为核心、完全 Serverless、可在 GitHub Pages/Vercel 上零成本部署的网页 Minecraft 体验，支持渐进式功能增强。
- **目标用户**：对体素游戏感兴趣的轻量玩家、教学演示需求用户，以及希望快速扩展的开发者与 AI 研究团队。
- **交付模式**：文档 → 代码实现 → 自动化测试 → 零人工部署 → 用户交付，全流程遵循工程化与质量门禁。
- **增量策略**：自 MVP 起步，逐步拓展至性能优化、玩法扩展、多人联机、生态系统等高级特性。

---

## 🧱 核心特性总览

1. **完全 Serverless**：纯前端实现，兼容 GitHub Pages、Vercel 等静态托管平台。
2. **渐进式模块化架构**：以 Chunk、渲染、玩家、交互、存档为核心模块，便于扩展与复用。
3. **Chunk 分块渲染架构**：支持 16x16x64 Chunk、动态加载与面剔除，显著提升性能并支持无限世界扩展。
4. **AI 友好型文档体系**：每份文档均提供结构化步骤、明确验收标准、跨文档引用，支持自动化阅读与执行。
5. **工程化管理模式**：结合网页游戏行业最佳实践与敏捷方法，辅以度量指标和质量门禁，确保交付可控。

详细技术说明请参阅 [03_技术体系与架构设计](docs/03_技术体系与架构设计.md)。

## 🔄 推荐工作流

1. **启动阶段**：阅读 01/07 文档，完成项目章程确认与工程管理设置。
2. **环境与工具准备**：按 00 文档完成依赖安装、工具链配置及基础验证。
3. **需求与设计评审**：结合 02、03、04、05 文档完成功能/架构/UI 三方评审。
4. **迭代开发**：依据 06 任务清单驱动迭代，遵循 08 编码规范，执行 09 测试计划。
5. **部署与交付**：按 10 文档完成构建、部署、监控配置；最终执行 11 检查清单完成封版交付。

## ✅ 测试与质量保障

- `npm run test`：运行 Vitest 单元测试（watch 模式）。
- `npm run test:coverage`：运行全部测试并生成 v8 覆盖率报告。
- 覆盖率目标：语句 ≥ 60%，当前已达 98.91%。
- 所有测试位于 `src/__tests__/` 目录，可根据模块拆分新增。
- 测试统计：6 个测试文件，41 个测试用例，全部通过 ✅
