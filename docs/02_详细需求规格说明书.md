## 2. 用户画像与用例

### 2.1 用户画像

#### 画像1：教学演示者
- **背景**：教师、培训师、技术分享者
- **目标**：快速展示体素游戏原理、Three.js 应用
- **关注点**：易部署、易修改、可定制
- **技能**：基础 JavaScript、Web 开发

#### 画像2：学习者
- **背景**：前端开发者、游戏开发初学者
- **目标**：学习 Three.js、理解游戏架构
- **关注点**：代码清晰、文档详细、调试友好
- **技能**：前端基础、愿意学习新技术

#### 画像3：AI 开发系统
- **背景**：自动化开发工具链
- **目标**：读取文档、生成代码、运行测试、部署
- **关注点**：结构化文档、明确步骤、验收标准
- **技能**：遵循规则执行、日志审计

## 5. 交互流程与场景描述

### 5.1 游戏启动流程

```
[用户打开网页]
    ↓
[加载 Three.js、依赖库]
    ↓
[显示开始界面 + 操作提示]
    ↓
[用户点击画布]
    ↓
[锁定鼠标，开始游戏循环]
    ↓
[生成初始地形]
    ↓
[玩家控制可用，开始游戏]
```

### 5.2 方块交互流程

```
[用户移动鼠标，准星对准方块]
    ↓
[Raycaster 检测目标方块]
    ↓
[显示高亮边框（可选）]
    ↓
├── [用户左键点击] → [破坏方块] → [移除几何体] → [更新 Chunk 缓存]
└── [用户右键点击] → [放置方块] → [创建几何体] → [更新 Chunk 缓存]
    ↓
[触发自动保存（可选）]
```

### 5.3 碰撞检测流程

```
[用户按下移动键]
    ↓
[计算目标位置]
    ↓
[执行 AABB 碰撞检测]
    ↓
├── [无碰撞] → [更新玩家位置]
└── [有碰撞] → [停止移动或滑动]
    ↓
[更新相机位置]
```

## 6. 数据需求与存储方案

### 6.1 世界数据结构

```javascript
{
  "version": "1.0",
  "worldName": "MyWorld",
  "seed": 12345,
  "createdAt": "2024-01-01T00:00:00Z",
  "lastModified": "2024-01-02T12:30:00Z",
  "playerState": {
    "position": { "x": 0, "y": 20, "z": 0 },
    "rotation": { "pitch": 0, "yaw": 0 },
    "velocity": { "x": 0, "y": 0, "z": 0 },
    "inventory": [
      { "blockType": "grass", "count": 64 },
      { "blockType": "stone", "count": 32 }
    ],
    "selectedSlot": 0
  },
  "chunks": [
    {
      "chunkId": "0,0,0",
      "blocks": [
        { "pos": [0, 0, 0], "type": "grass" },
        { "pos": [1, 0, 0], "type": "dirt" }
      ]
    }
  ],
  "settings": {
    "renderDistance": 4,
    "fov": 75,
    "mouseSensitivity": 0.002
  }
}
```

### 6.2 存储方案比较

| 方案 | 容量 | 性能 | 适用场景 |
| --- | --- | --- | --- |
| **LocalStorage** | 5-10 MB | 同步读写 | 小型世界（MVP） |
| **IndexedDB** | 无限制（实际受浏览器限制） | 异步读写 | 大型世界、多存档 |
| **File System API** | 用户授权 | 高性能 | 未来扩展（实验性） |

### 6.3 数据需求清单

| ID | 需求描述 | 数据结构 | 存储位置 |
| --- | --- | --- | --- |
| DR-01 | 存储世界方块数据 | Chunk 数组 | IndexedDB |
| DR-02 | 存储玩家状态 | Player 对象 | IndexedDB |
| DR-03 | 存储游戏设置 | Settings 对象 | LocalStorage |
| DR-04 | 存储存档列表 | Array<SaveInfo> | LocalStorage |
