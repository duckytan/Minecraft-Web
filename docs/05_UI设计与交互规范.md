## 1. 设计原则

1. **沉浸式体验**：界面元素尽量简洁，优先突出游戏画面
2. **清晰反馈**：每个操作有视觉/声音（可选）反馈
3. **一致性**：颜色、字体、交互逻辑保持统一
4. **可扩展性**：为未来背包、任务系统预留区域
5. **可访问性**：确保文本清晰、对比度达标、键盘可操作

## 3. 交互流程

### 3.1 启动流程

```
[加载页面] → [显示封面 + “点击开始”提示] → [点击画布] → [锁定鼠标] → [显示 HUD]
```

### 3.2 方块选择栏交互

```
[玩家按下数字键 1-9]
      ↓
[高亮对应槽位]
      ↓
[更新当前方块类型]
      ↓
[UI 显示变更反馈]
```

### 3.3 鼠标锁定交互

```
[首次进入页面]
      ↓
[显示 “点击屏幕以开始” 提示]
      ↓
[玩家点击 → Request Pointer Lock]
      ↓
[成功：隐藏提示 + 激活 HUD]
```

## 4. 视觉设计规范

### 4.1 色彩规范

| 用途 | Hex | 说明 |
| --- | --- | --- |
| 主要字体 | `#FFFFFF` | HUD 文本 |
| 警告提示 | `#FF9800` | 操作提示/警告 |
| HUD 背景 | `rgba(0, 0, 0, 0.35)` | 半透明背景 |
| 选中高亮 | `#4CAF50` | 选中方块槽位 |

### 4.2 字体与排版

- 字体族：`"Segoe UI", "Helvetica", "Arial", sans-serif`
- 字号：
  - HUD 文本：14px
  - 方块栏数字：16px（加粗）
- 推荐使用 CSS 自适应单位（`rem`）

### 4.3 准星设计

```css
#crosshair {
  position: fixed;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
  width: 20px;
  height: 20px;
}
#crosshair::before,
#crosshair::after {
  content: '';
  position: absolute;
  background: white;
}
#crosshair::before {
  left: 50%;
  top: 0;
  width: 2px;
  height: 100%;
  transform: translateX(-50%);
}
#crosshair::after {
  top: 50%;
  left: 0;
  width: 100%;
  height: 2px;
  transform: translateY(-50%);
}
```

## 5. 输入与控制映射

| 操作 | 输入设备 | 默认映射 | 可配置 | 提示位置 |
| --- | --- | --- | --- | --- |
| 移动 | 键盘 | `W/A/S/D` | ✅ | 操作提示 |
| 跳跃 | 键盘 | `Space` | ✅ | 操作提示 |
| 奔跑 | 键盘 | `Shift` | ✅ | 操作提示 |
| 放置方块 | 鼠标 | 右键 | ✅ | 操作提示 |
| 破坏方块 | 鼠标 | 左键 | ✅ | 操作提示 |
| 切换方块 | 键盘 | `1-9` | ✅ | 方块栏 |
| 释放鼠标 | 键盘 | `ESC` | ❌ | 提示 overlay |

> 用户可在配置面板中调整键位，默认配置在 `src/config/keybindings.ts`

## 6. 响应式与多设备适配

### 6.1 桌面端

- UI 元素固定位置，但支持 16:9 / 16:10 / 21:9
- HUD 使用 `vh` / `vw` 单位自适应
- 画布填满窗口，禁止滚动条

### 6.2 平板与触屏（扩展）

- 提供虚拟摇杆与按钮（未来）
- HUD 扩大触碰区域，避免误触

### 6.3 小屏适配策略

| 屏幕宽度 | 策略 |
| --- | --- |
| ≥ 1200px | 全尺寸布局 |
| 768px-1199px | 缩小 HUD 20%，保持准星大小 |
| ≤ 767px | 使用触屏模式（未来扩展） |

## 7. 无障碍与可访问性

1. **键盘导航**：在鼠标锁定前，确保元素可通过 Tab 操作
2. **色彩对比**：文字与背景对比度 ≥ 4.5:1
3. **提示文本**：使用简单易懂语言，避免行话
4. **提示持久性**：首次提示显示 5 秒，可通过 `H` 键再现提示
5. **动效控制**：提供选项关闭 HUD 动画（在设置面板）

---

## 8. 实现建议

- 使用 **CSS Modules** 或 **Tailwind**（可选）保持风格一致
- HUD 渲染使用 **HTML + CSS**，避免在 Three.js 内绘制
- 使用 **React/Vue** 仅在引入框架时考虑；MVP 使用原生 DOM 操作
- 将 UI 与游戏逻辑分离：UI 通过事件监听状态变化
