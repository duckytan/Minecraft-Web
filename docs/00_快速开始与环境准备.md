## 1. 概述与前置条件

### 1.1 项目特点
- **完全 Serverless**：无需后端服务器，纯前端运行
- **零构建启动（可选）**：可使用 CDN 直接开发，无需 Node.js
- **进阶构建（推荐）**：使用 Vite 进行模块化开发与优化构建

### 1.2 前置知识
- 基础 JavaScript/TypeScript
- Three.js 基础概念（场景、相机、渲染器、几何体）
- Git 版本控制
- 命令行工具使用

### 1.3 开发模式选择

| 模式 | 适用场景 | 工具链 | 部署目标 |
| --- | --- | --- | --- |
| **零构建模式** | 快速原型、学习测试 | 浏览器 + CDN | GitHub Pages（直接推送） |
| **Vite 构建模式**（推荐） | 生产开发、模块化 | Node.js + Vite | Vercel / GitHub Pages + Actions |

## 3. 安装与配置步骤

### 3.1 克隆仓库

```bash
# 克隆项目
git clone https://github.com/YOUR_USERNAME/web-minecraft.git
cd web-minecraft

# 切换到开发分支（如有）
git checkout -b dev
```

### 3.2 零构建模式（快速启动）

```bash
# 使用 Python 自带服务器
python3 -m http.server 8000

# 或使用 npx（无需安装）
npx serve -p 8000

# 或使用 VS Code 的 Live Server 插件（一键启动）
```

访问：`http://localhost:8000`

**优点**：
- 无需安装依赖
- 适合快速验证

**限制**：
- 无法使用模块化
- 无法使用 TypeScript
- 调试工具受限

### 3.3 Vite 构建模式（推荐）

#### 步骤 1：安装依赖

```bash
# 使用 npm
npm install

# 或使用 pnpm（速度更快）
pnpm install
```

#### 步骤 2：启动开发服务器

```bash
npm run dev
# 或
pnpm dev
```

访问：`http://localhost:5173`（Vite 默认端口）

#### 步骤 3：构建生产版本

```bash
npm run build
npm run preview  # 预览构建结果
```

## 4. 验证脚本与检查清单

### 4.1 环境验证脚本

创建 `scripts/verify-env.sh`：

```bash
#!/bin/bash
echo "========== 环境验证脚本 =========="

# 检查 Node.js
if command -v node &> /dev/null; then
    NODE_VERSION=$(node --version)
    echo "✅ Node.js: $NODE_VERSION"
else
    echo "❌ Node.js 未安装"
    exit 1
fi

# 检查 npm
if command -v npm &> /dev/null; then
    NPM_VERSION=$(npm --version)
    echo "✅ npm: $NPM_VERSION"
else
    echo "❌ npm 未安装"
    exit 1
fi

# 检查 Git
if command -v git &> /dev/null; then
    GIT_VERSION=$(git --version)
    echo "✅ Git: $GIT_VERSION"
else
    echo "❌ Git 未安装"
    exit 1
fi

# 检查依赖安装
if [ -d "node_modules" ]; then
    echo "✅ 依赖已安装"
else
    echo "⚠️  依赖未安装，请运行 npm install"
fi

echo "========== 验证完成 =========="
```

运行：
```bash
chmod +x scripts/verify-env.sh
./scripts/verify-env.sh
```

### 4.2 功能验证清单

| 验证项 | 验证方法 | 预期结果 |
| --- | --- | --- |
| **Three.js 加载** | 打开浏览器控制台，检查是否有加载错误 | 无 404 错误，THREE 对象可访问 |
| **WebGL 支持** | 访问 `https://get.webgl.org/` | 显示旋转立方体 |
| **鼠标锁定 API** | 点击画布，检查是否锁定鼠标 | 鼠标消失，可控制视角 |
| **本地存储** | 打开 DevTools → Application → Local Storage | 可读写数据 |
| **模块加载** | 检查 Network 面板，查看 JS 文件加载 | 所有模块正常加载 |

## 5. 常见问题排查

### 5.1 问题：Three.js 加载失败（404）

**现象**：
```
GET https://cdn.jsdelivr.net/npm/three@0.160.0/build/three.module.js net::ERR_FAILED
```

**解决方案**：
1. 检查网络连接
2. 尝试更换 CDN（unpkg.com 或 esm.sh）
3. 使用本地安装：`npm install three`

### 5.2 问题：Vite 启动失败

**现象**：
```
Error: Cannot find module 'vite'
```

**解决方案**：
```bash
rm -rf node_modules package-lock.json
npm install
```

### 5.3 问题：鼠标锁定不生效

**现象**：点击画布后鼠标未锁定

**解决方案**：
1. 确保使用 HTTPS 或 localhost
2. 检查浏览器权限设置
3. 使用现代浏览器（Chrome/Firefox 最新版）

### 5.4 问题：性能问题（FPS < 30）

**排查步骤**：
1. 打开 Chrome DevTools → Performance
2. 录制 3 秒运行时间
3. 查看主线程瓶颈（通常是渲染或 GC）
4. 参考 [08_编码规范、最佳实践与复用策略](08_编码规范、最佳实践与复用策略.md) 进行优化

## 6. AI 执行 SOP（标准操作程序）

### 6.1 初始化工作流

```
1. 读取本文档，确认环境需求
2. 执行环境验证脚本（4.1 节）
3. 根据验证结果，选择开发模式（零构建 or Vite）
4. 执行功能验证清单（4.2 节）
5. 如遇问题，按 5 节排查并记录
6. 完成后，在任务日志中标记 ✅ 环境就绪
```

### 6.2 每日启动检查

```
1. 拉取最新代码：git pull origin dev
2. 检查依赖变更：npm install（如 package.json 更新）
3. 启动开发服务器：npm run dev
4. 访问浏览器，确认无控制台报错
5. 开始开发任务
```

### 6.3 提交前检查

```
1. 运行 lint：npm run lint
2. 运行类型检查：npm run type-check（如使用 TypeScript）
3. 运行测试：npm run test（如有）
4. 本地构建：npm run build
5. 预览构建结果：npm run preview
6. 确认无错误后提交
```
